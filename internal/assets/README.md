# MailSalonGUI icon

`icon.png` is the 512 × 512 transparent PNG used by the embedded app resource,
Linux icon installation and Fyne packaging metadata. The icon is distributed
under the project's GPL-3.0-only license.

Created for MailSalonGUI with the built-in image generation tool, then resized
for desktop packaging. Original generation prompt:

> Use case: logo-brand. Asset type: final square desktop app icon for
> MailSalonGUI, a Go/Fyne email client. Create one polished minimalist application
> icon: a bold ivory envelope with a clear folded flap, centered on a rich plum
> rounded-square tile with rose-pink accents. A small rose seal where the flap
> meets the envelope, no letters or text. Flat vector-like graphic with smooth
> crisp edges, extremely simple geometry and high contrast, recognizable at 24
> and 32 pixels. Straight-on view, square composition, evenly inset tile,
> symmetric centered envelope occupying most of the tile. Transparent canvas
> around the rounded tile, no external drop shadow, no mockup, no extra objects,
> no typography, no watermark. Restrained friendly elegance. Single icon only.
